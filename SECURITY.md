# Beveiliging

Dit is een fictieve portfolio-case met lokale demonstratie-identiteiten.
Gebruik geen echte klantgegevens of persoonlijke dossiers in issues, fixtures
of logs. Publiceer geen tokens, tenantconfiguratie of connectorcredentials.

Meld een mogelijk lek via een private security advisory in GitHub als die
functie beschikbaar is; plaats anders eerst een issue zonder exploitatiedetails
om een privé meldkanaal af te spreken. Er is geen productie-SLA.

De demo is geen security-certificering of juridisch complianceadvies.
Tenantgebruik vereist de acceptatiecriteria en controles uit de bouwgids.
