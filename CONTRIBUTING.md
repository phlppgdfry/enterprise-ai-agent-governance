# Bijdragen

Voer `make verify` uit vóór een pull request. Beschrijf het concrete probleem,
gewijzigde gedrag en de test die het bewijst. Wijzig fictieve beleidsregels
tegelijk in bron, contract, tests en documentatie. Gebruik uitsluitend
synthetische voorbeelden. Cloudresultaten vragen apart bewijs; een lokale
simulatie mag nooit als tenantmeting of klantresultaat worden gepresenteerd.
